# Scolaris — Site vitrine

Site marketing statique de Scolaris (SaaS de gestion scolaire). Hébergé séparément
de l'application principale pour pouvoir le tester en ligne (GitHub Pages) sans
dépendre du dépôt applicatif.

## Pages
- `index.html` — page d'accueil
- `ecoles.html` — annuaire des écoles ouvertes aux inscriptions
- `suivi.html` — suivi d'un dossier de pré-inscription

## Déploiement
GitHub Pages, branche `main`, racine `/`.
